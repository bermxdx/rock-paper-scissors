# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript.

## Demo

Open `index.html` in your browser, or [play it live on GitHub Pages](#) once deployed (see below).

## How to Play

Click one of the three buttons (Rock, Paper, or Scissors). The computer picks randomly, and the result pops up in an alert.

## Tech

- HTML
- Vanilla JavaScript (no frameworks or build tools)

## Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/bermxdx/rock-paper-scissors.git
   ```
2. Open `index.html` in your browser — that's it, no build step required.

## Deploying with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment", set the source to your `main` branch, root folder.
4. Your game will be live at `https://bermxdx.github.io/rock-paper-scissors/`.
